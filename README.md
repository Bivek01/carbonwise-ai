# 🌱 CarbonWise AI

An AI-powered Carbon Footprint Tracking Platform that helps users monitor, analyze, and reduce their environmental impact through intelligent insights and interactive dashboards.

---

## 🚀 Features

- 🌍 Carbon Footprint Calculator
- 🤖 AI Sustainability Coach
- 📊 Interactive Dashboard
- 📈 Data Visualization with Charts
- 🎯 Eco Challenges
- 📱 Fully Responsive Design
- ⚡ Fast Performance
- 🎨 Modern Glassmorphism UI
- 🔥 AI Evaluation Dashboard
- 🌙 Smooth Animations

---

## 🛠 Tech Stack

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- Recharts
- Google Gemini API
- JavaScript
- HTML5
- CSS3
