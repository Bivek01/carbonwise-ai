## 🌍 About The Project

CarbonWise AI is an intelligent sustainability platform that helps users calculate, monitor, and reduce their carbon footprint through AI-powered insights and interactive analytics.

The application combines modern web technologies with Artificial Intelligence to provide personalized sustainability recommendations, carbon emission tracking, and an advanced evaluation dashboard.

# 🛠 Installation

Clone the repository

```bash
git clone https://github.com/Bivek01/carbonwise-ai.git
```

Go to project directory

```bash
cd carbonwise-ai
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Create production build

```bash
npm run build
```

---

# 🔑 Environment Variables

Create a `.env` file and add:

```env
VITE_GEMINI_API_KEY=YOUR_API_KEY
```
